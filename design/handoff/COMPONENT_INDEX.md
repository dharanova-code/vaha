# Component Index

The following reusable layout components are declared in the Vaha design system.

---

## 1. Page Header (Welcoming Greeting)
*   **Typography:** EB Garamond, Display/Headline-sm.
*   **Description:** Top greeting used to anchor page entries, displaying a welcoming title with generous breathing spacing.

---

## 2. Continuing Anchor (Continue Where You Left Off)
*   **Container Style:** Borderless, flat background (#F5F2EC) with a 4px corner radius.
*   **Description:** Centered focus block on the Home page detailing the most recent unfinished capture.

---

## 3. Flat Action Button
*   **Shape:** Rectangular, sharp edges, 4px corner radius.
*   **Borders:** 1px solid (#E2DFD9), transparent/flat fill. Active state shifts border color to Muted Copper (#C07D53).
*   **Description:** Used for primary and secondary inline user selections.

---

## 4. Suggested Reflection (Pull-Quote)
*   **Container Style:** Borderless flat blockquotes with copper accent vertical indicator bars.
*   **Description:** AI-generated summary recommendations and insights.

---

## 5. Ledger Table (Monoline List)
*   **Style:** Stacked text items separated by a thin 1px horizontal line (#E2DFD9 at 15% opacity).
*   **Description:** Standard format for Settings, Device Status, and file status logs.
