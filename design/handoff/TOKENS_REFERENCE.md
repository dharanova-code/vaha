# Tokens Reference

This document refers to the active Design System styling tokens attached to Google Stitch.

---

## 1. Colors
*   **Warm Paper (Layer 0 Background):** `#FAF8F5`
*   **Warm Paper Secondary (Layer 1 Container):** `#F5F2EC`
*   **Deep Forest Green (Primary Text):** `#1B3629`
*   **Natural Stone (Secondary Text/Icons):** `#7A7265`
*   **Muted Copper (Accents/Highlights):** `#C07D53`
*   **Border Stone:** `#E2DFD9`

---

## 2. Typography
*   **Headline Font (Serif):** EB Garamond (emotional greeting headers, capture titles, insights)
*   **Body & Label Font (Sans):** Inter (transcripts, UI actions, status metrics)
*   **Display Large:** 36px (line height: 44px, serif)
*   **Headline Large:** 24px (line height: 32px, serif)
*   **Body Medium:** 16px (line height: 26px, sans)
*   **Label Small:** 13px (line height: 18px, sans)
*   **Metadata Small:** 12px (line height: 16px, sans)

---

## 3. Spacing & Radius
*   **Base Spacing Grid:** 8px
*   **Mobile Screen Margin:** 24px (left/right column margins)
*   **Corner Radius (Medium):** 4px (containers, input focus states)
*   **Corner Radius (Small):** 2px (buttons)
*   **Vertical Section Margins:** 48px to 64px

---

## 4. Motion & Animation
*   **Curve:** `cubic-bezier(0.25, 1, 0.5, 1)` (linear-out-slow-in)
*   **Duration:** 120ms (standard transitions)
*   **Breathing Animation:** Sinusoidal opacity oscillation (2500ms cycle duration) for sync, loading, and pairing states.
