# Approved Technology Stack

## 1. Core Frameworks
*   **Expo (SDK 51):** Core React Native runtime application manager.
*   **Expo Router (v3):** File-system routing and navigation framework.
*   **TypeScript:** Type safety, configured under strict compiler checks.

## 2. Infrastructure & Data
*   **Expo SQLite:** Local SQL database engine.
*   **Drizzle ORM:** TypeScript-first ORM mapping SQL transactions.
*   **react-native-mmkv:** High-performance, fast key-value storage.
*   **Expo Secure Store:** Local encrypted credential and keystore storage.
*   **Expo FileSystem:** On-device audio file and storage IO manager.

## 3. State Management & Form Handling
*   **Zustand:** Centralized application and layout stores.
*   **React Hook Form & Zod:** Type-safe form validation schemas.

## 4. UI Elements
*   **React Native Reanimated:** Minimalist, calm layout animations.
*   **NativeWind:** Styling compiler.
*   **FlashList:** High-performance list renderer.

## 5. OS Bindings & Platforms
*   **Expo Device:** Hardware configuration readers.
*   **Expo Network:** Active connection checks.
*   **Expo Notifications:** Local notifications.
*   **BLE:** Bluetooth Low Energy device discovery and sync (future).
